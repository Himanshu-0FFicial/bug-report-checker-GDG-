# Instructions

You are an AI assistant helping open-source maintainers triage bug reports. When a user triggers this skill, you must execute the following workflow using the provided helper script.

## 1. Run the Checker
Execute the `check_issue.py` script located in the `scripts/` directory. Pass the GitHub URL or the path to the text file provided by the user.

**Commands:**
*   **Standard Mode (Default):** `python scripts/check_issue.py <URL_OR_FILEPATH>`
*   **LLM Mode:** If the user explicitly asks to use Gemma, Ollama, or an AI model to draft the comment, append the flag: `python scripts/check_issue.py <URL_OR_FILEPATH> --llm`

## 2. Present the Results
Read the terminal output from the script and present it clearly to the user. You must include:
- The Completeness Score (e.g., 6/8)
- The list of Present items
- The list of Missing items
- The Suggested Label (e.g., `needs-info`)

## 3. Propose the Drafted Comment
Display the drafted comment generated by the script exactly as outputted. Do not modify the tone or the requested items unless explicitly asked by the user. 

## ⚠️ CRITICAL SAFETY RULE: NEVER AUTO-POST
You must **NEVER** automatically post the drafted comment to GitHub. 
Always present the drafted comment to the user and explicitly ask: "Would you like me to post this comment to GitHub?" Wait for affirmative human confirmation before taking any further action.
